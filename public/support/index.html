SUPPORT

Need help with Open Social P2P?

OSP is still in Product Alpha. This page is the current support and contact point for the project while the public testing tools are being finished.

Get help or report a bug

If something is broken, confusing or not working as expected, open an issue in the OSP GitHub project. Describe what you were trying to do, what happened, and what you expected instead.

The app's Advanced screen can copy technical details for a bug report without including network addresses. Paste those details into the issue when they are relevant.

Open a GitHub issue

Report content or a safety concern

During the Product Alpha, use the project issue tracker to flag content or behaviour that needs review. Include the OSP profile, post or reply identifier when you have it and explain what you observed.

GitHub issues are public. Do not put private personal information, passwords, recovery words, private keys, pairing codes or other secrets in a report. A private abuse-reporting channel is part of the safety work before broader public testing.

Report a concern →

Security problems

Please do not publish exploit details, credentials or private keys in a public issue. Check the repository's Security page for the current private vulnerability-reporting options.

Open the Security page →

Contact

The project is currently maintained through GitHub. For support that does not belong in an issue, contact the maintainer through the Jayotis GitHub profile.

Before you post

Never share your OSP recovery words, private keys or pairing secrets with support. OSP support should not need them.
