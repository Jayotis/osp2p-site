SUPPORT

Need help with Open Social P2P?

OSP is still in Product Alpha. This page is the current support and contact point for the project while the public testing tools are being finished.

Get help

For help using Open Social P2P, email support@osp2p.com.

If something is broken, confusing or not working as expected, you can also open a public issue in the OSP GitHub project. Describe what you were trying to do, what happened, and what you expected instead.

The app's Advanced screen can copy technical details for a bug report without including network addresses. Include those details when they are relevant.

Email OSP support

Open a GitHub issue →

Report content or a safety concern

Use the private OSP report form to report a post, reply or profile, or to appeal something the project has hidden. Reports are reviewed against the published OSP rules.

Open the report form

Read the OSP Terms of use →

Security problems

Please do not publish exploit details, credentials or private keys in a public issue. Use the repository's Security page for private vulnerability reporting.

Open the Security page →

Contact

Email support@osp2p.com for general support or questions about Open Social P2P.

Before you contact support

Never share your OSP recovery words, private keys or pairing secrets with support. OSP support should not need them.
